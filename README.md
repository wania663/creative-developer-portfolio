# Creative Developer Portfolio

Multi-file portfolio in pure HTML, CSS and JavaScript. No build step, no installs.

## Run
1. Extract the ZIP.
2. Double-click `index.html` (or right-click → Open with Chrome).
3. Optional: VS Code → "Live Server" extension → Go Live.

## Customize
- Name & email: top of `js/main.js` (`CONFIG`).
- Photo: replace `assets/profile.svg` with your photo (keep the filename or edit the `<img>` in `index.html`).
- Projects, text, social links: `index.html`.
- Colors & fonts: `:root` variables at the top of `css/style.css`.

## Structure
```
index.html
css/style.css
js/main.js
assets/profile.svg
```

## Features
Loader · custom cursor · wavy hero title on hover · full-screen menu · scroll reveals · expertise hover chips · marquee · project cards · working contact form (opens your mail app) · fully responsive.
